# Capability evidence scoring

Keep the capability matrix honest: for one named competitor, propose a 0–3 score per capability — but only where the evidence actually speaks.

## When to use
When new competitive signals land for a rival, when the matrix looks stale or guessed, or before a battlecard is built on it.

## Inputs
- The competitor's signals and synthesized themes.
- The current capability matrix and its history.
- Market/review evidence, with dates.

## The scale
- **0 — none.** No evidence they do this, or a known gap.
- **1 — partial.** Early, weak, or only mentioned; a single soft mention is a 1, never higher.
- **2 — good.** A solid, shipped capability with real corroboration.
- **3 — strong.** Differentiated and proven; multiple independent confirmations.

## Process
1. **Cite or omit.** Every score names the signals that justify it. If the evidence doesn't address a capability, omit it — don't restate the current score, don't infer from brand reputation.
2. **Date matters.** Prefer recent evidence; an old launch note doesn't prove a current strength.
3. **Direction honesty.** If the evidence contradicts the current score (theirs got stronger, or a claimed strength looks thin), say so in the rationale.
4. **One-line rationale.** Tie the number to the cited evidence in a sentence a reviewer can verify in thirty seconds.

## Principles
- Independent corroboration raises a score; a single mention never exceeds 1.
- Silence is not a zero — omit what the evidence doesn't address rather than guessing the matrix full.
- Abstain when thin; a smaller, honest matrix beats a complete, fictional one.

## Output
Per capability: a 0–3 score, the cited signals, and a one-line rationale a reviewer can open and verify. Proposed for ratification.
